## 🧾 Descrição do Projeto

O presente projeto tem como proposta o desenvolvimento de uma aplicação web voltada para a **centralização e análise de dados de vendas provenientes de marketplaces**.

A solução atende empresas que utilizam plataformas digitais como principal canal de vendas, permitindo uma visão mais organizada e estratégica das informações comerciais.

---

## 🎯 Objetivo

Desenvolver um sistema capaz de reunir e apresentar dados de vendas de diferentes marketplaces em um único ambiente, facilitando a análise de desempenho e apoiando a tomada de decisões.

---

## ⚙️ Funcionamento do Sistema

A aplicação permite ao usuário visualizar dados de vendas de forma consolidada por meio de dashboards e indicadores visuais.

### Funcionalidades principais:

- 📈 Acompanhamento de desempenho de produtos  
- 💰 Visualização de métricas de vendas  
- 📊 Comparação de resultados por período  
- 🔍 Identificação de tendências

## 🧠 Contexto

O crescimento do comércio eletrônico no Brasil e a forte presença dos marketplaces criaram um cenário onde muitos empreendedores dependem dessas plataformas para vender.

Nesse contexto, a análise de dados ainda é, muitas vezes, manual ou limitada, o que reforça a necessidade de soluções que centralizem e organizem essas informações.
